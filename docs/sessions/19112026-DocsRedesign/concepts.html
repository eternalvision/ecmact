Eight widgets, twelve examples, one starter

Concepts for the rewritten widget gallery, the rewritten examples and the restyled starter. The page chrome stays monochrome, as the design study decided. Each widget and each example is a small world of its own, so the difference between them is the first thing a visitor sees.

Widgets

Eight custom elements made with defineWidget. No two share a job or a look. Each keeps its character inside any host and lets the host tune a few custom properties. The mocks are sketches of the direction, drawn with CSS only, because tags creates HTML elements and has no SVG namespace (checked in src/core/element.ts).

A print shop's quote: copies, ink colours and paper stock, with price breaks.

Swiss poster. One grotesque, a red bar, a strict grid and a numeral as large as the widget.
Interaction
Step the copies through the price breaks, pick inks and stock, request the quote.

Examples

Twelve examples. Each one runs inside its own stage, works with the network unplugged, and shows the source that produced it. A failure is always one control away, because the failure path is the part people need to copy.

E1 · exposure · answers the old id counter · guide: signals

Exposure triangle

Aperture, shutter and ISO as three signals; the exposure value is computed from them.

Style
Segmented LCD of a camera top plate, with hard plastic keys.
Interaction
Step each value. With the lock on, one press changes two signals in a batch and the value stays.
ECMact
signalcomputedbatcheffectuntrackedem + css
Proves
A counter beside each readout shows which texts ran again, and which did not.

Setlist for tonight

A band's running order: reorder the songs and keep an eye on the curfew.

Style
Gaffer tape on a black stage floor, written with a marker.
Interaction
Add a song, move it up or down from the keyboard, strike it once played.
ECMact

Wood-type poster

Field notebook

A bird-watcher's tally that is still there after a reload.

Coverage matrix

Every API area of the README is exercised by at least one concept. The last column counts them. The addendum asks for this table to exist as a test, so that a later edit cannot drop an area without notice.

Columns W1 to W8 are the widgets and E1 to E12 the examples, in the order above. A widget is not a form field: defineWidget documents no field option, so forms are covered by an example.

The starter, restyled

The first screen of npm create ecmact, app template, in the site's ink and paper. The blue glow and the hexagon image go. The mark is drawn from the same geometry as the site header. The structure of the project stays: one component, one test, one hint about where to edit. Both themes are shown; the real page follows the system.
