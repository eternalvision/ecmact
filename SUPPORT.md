# Getting help

- Start with the [quick start and API reference](README.md#quick-start).
- Try the [app starter](https://eternalvision.github.io/ecmact/), [widget demo](https://eternalvision.github.io/ecmact/widget/) and [embedding example](https://eternalvision.github.io/ecmact/widget/embed.html).
- For reproducible defects, use the bug report template in [Issues](https://github.com/eternalvision/ecmact/issues/new/choose).
- For ideas, use the feature request template and explain the problem you want to solve.
- For usage questions, use the question template and include the relevant package version and a minimal example.
- For vulnerabilities, follow the [private reporting process](SECURITY.md).

Include whether you are using the library directly, the app starter or the widget starter. For browser issues, include the browser version and whether Shadow DOM is enabled. For scaffolding issues, include the Node.js version, package manager and command used.

This is a community-maintained project. Support is best effort; no response time or paid support service is implied.
