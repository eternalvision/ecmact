# {{name}}

An [ECMact](https://github.com/eternalvision/ecmact) app built with Vite and TypeScript.

## Scripts

| Command           | Description                      |
| ----------------- | -------------------------------- |
| `npm run dev`     | Start the dev server             |
| `npm run build`   | Type check and build to `dist/`  |
| `npm run preview` | Preview the production build     |
| `npm test`        | Run the tests (Vitest, happy-dom) |

## Where to look

- `src/main.ts` mounts the app.
- `src/counter.ts` is a component built from a signal; `src/counter.test.ts` tests it.
- The ECMact documentation covers props, signals, routing and data fetching: https://github.com/eternalvision/ecmact#readme
